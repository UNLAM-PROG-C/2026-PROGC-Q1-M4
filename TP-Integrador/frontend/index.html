Sobre el proyecto

IdentifAI es una plataforma web distribuida y de alta disponibilidad diseñada para el reconocimiento automático de objetos en imágenes utilizando Inteligencia Artificial. La aplicación permite a los usuarios cargar archivos multimedia de manera intuitiva y recibir un análisis preciso en tiempo real.

Tecnologías utilizadas

La plataforma utiliza una arquitectura de microservicios completamente contenedorizada con Docker. Combina un frontend moderno en JavaScript con un backend en Java, interconectados de forma asíncrona mediante el broker de mensajería RabbitMQ hacia un motor de procesamiento en Python potenciado por el modelo de visión computacional YOLOv8.
