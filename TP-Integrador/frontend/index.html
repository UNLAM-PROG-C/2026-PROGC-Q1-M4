Sobre el proyecto

IdentifAI es una plataforma web distribuida y de alta disponibilidad diseñada para el reconocimiento automático de objetos en imágenes utilizando Inteligencia Artificial. La aplicación permite a los usuarios cargar archivos multimedia de manera intuitiva y recibir un análisis preciso en tiempo real.

Tecnologías utilizadas

La plataforma utiliza una arquitectura de microservicios completamente contenedorizada con Docker Compose. El frontend en HTML/CSS/JavaScript vanilla se comunica con un backend en Java (HttpServer nativo), que encola las imágenes en RabbitMQ usando el patrón reply-to con correlation ID. El worker en Python recibe las imágenes, las preprocesa en GPU (CUDA 12.1.1, PyCUDA) —grayscale, normalización e inversión— y ejecuta la inferencia con una CNN de 8 kernels CUDA (convolución, ReLU, batch norm, max pooling, densas, softmax) entrenada sobre Fashion MNIST con TensorFlow/Keras.
